# Security Policy

## Supported Versions

Only the latest released version of TranscriPy receives security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately in one of these ways:

- Use GitHub's [private vulnerability reporting](https://github.com/niewolski/TranscriPy/security/advisories/new) ("Report a vulnerability" in the **Security** tab).
- Or send an e-mail to bartosz@niewolski.com.

Please include a description of the issue, steps to reproduce it, and the affected version.

You can expect an initial response within 7 days. If the vulnerability is accepted, I will work on a fix and release it as soon as possible, and credit you in the release notes if you wish. If it is declined, I will explain why.
